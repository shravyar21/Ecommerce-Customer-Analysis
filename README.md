# Ecommerce Custmer Analytics
## Project Overview
This project analyzes e-commerce sales data using python to identify sales,profit, product, category, and regional trends.

## Dataset
The dataset contains:
- Order date
- Product Name
- Category
- Region
- Quantity
- Sales
- Profit

## Tools & Libraries
- Python
- Pandas
- Numpy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Monthly Sales Trend
- Highest Sales Month
- Lowest Sales Month
- Sales by Category
- Sales by Region
- Profit by Region
- Top 10 Products by sales
- Monthly Profit Trend
- Monthly Sales Trend
- Quantity Distribution
- Sales Market Share by Category

# Key Insights
- Electronics is the best-selling category
- Electronics is also the most profitable category
- West is the best-performing region by sales.
- Highest and Lowest sales months  were identified
- Top-perfoming products where identified using sales analysis
